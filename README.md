# Dental & Aesthetic Clinic Website

A promotional website for a dental and aesthetic clinic. It includes services, an explore section, and a promotional video.

## Features

- Responsive landing page (`index.html`)
- Styles in `css/` (`styles.css`, `explore.css`)
- Interactivity in `js/` (`main.js`, `explore.js`)
- Images under `image/`, `image 2/`, and `img/`
- Promotional video

## Structure

```
.
├── index.html
├── css/
│   ├── explore.css
│   └── styles.css
├── js/
│   ├── explore.js
│   └── main.js
├── image/
├── image 2/
└── img/
    └── explore/
```

## Running

Open `index.html` in a web browser. No build tools or dependencies are required.
